# Nothing SDK (not bundled)

Nothing's Glyph Matrix SDK EULA restricts redistribution. Obtain the AAR directly
from the official Nothing developer repository and, if you accept its terms, place:

    app/libs/glyph-matrix-sdk-2.0.aar

Source: https://github.com/Nothing-Developer-Programme/GlyphMatrix-Developer-Kit
License: https://github.com/Nothing-Developer-Programme/GlyphMatrix-Developer-Kit/blob/main/LICENSE.md

If absent, a stub backend is compiled and the app's editor remains operational.
The actual Phone (4a) Pro backend has NOT been tested on device.
