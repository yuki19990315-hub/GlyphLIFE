# AI会話・AIドット絵生成（Gemini BYOK 試験実装）

API参照： https://ai.google.dev/gemini-api/docs/generate-content/text-generation
モデル参照： https://ai.google.dev/gemini-api/docs/models
料金： https://ai.google.dev/gemini-api/docs/pricing

## 動作
- 初期値はオフラインの簡易定型返答（ペット）と手動ドット絵編集。
- 利用者がGoogle AI StudioからGemini APIキーを取得し、アプリ画面に入力した場合のみ、クラウド生成を手動実行。
- モデル `gemini-3.5-flash-lite`（2026-11-11の公式モデル一覧で確認したモデルID）。利用可能性と料金は契約・地域・時期で変わる。
- 実行時に会話/ペット設定、またはドット絵の生成指示がGoogleへ送信される。
- APIキーはComposeのメモリにのみ保持し、端末保存・GitHub保存・共有ログ出力はしない。プロセス終了で消去される。
- 無料枠の制限、プライバシー規約、課金を利用者が確認する。無料枠でも利用内容が提供元の改善に使用される条件があり得る。
- 生成APIリクエストはボタン操作した場合のみ送信し、起動時やバックグラウンド自動送信はしない。

## 安全上の境界
- AIの返答は文字列だけ。ペットのXPや所持品を更新できない。
- AIドット絵は `frames[1..8].pixels` を厳密に169桁0/1と検査し、描画・ゲーム状態へ反映前にパースする。
- 不正な生成、エラー、ネットワーク障害は失敗と表示し、既存ドット絵を破壊しない。
- APIキーをアプリに固定したり、第三者へ配布するアプリに秘密鍵を内蔵したりしない。一般公開時にはユーザー別サーバー代理APIと認証の再設計を推奨。

## 検証
コード・JSONパースのユニットテストはCI対象。実際のGeminiネットワーク呼び出しは**ユーザーのAPIキー未提供のため未検証**。無制限・無料での利用を保証しない。
