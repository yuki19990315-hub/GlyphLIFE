# Monster Quest — AIパーツ装備の仕様（v2.6）

## 実装済み

- 素体：四足獣、竜、二足、巨像、蛇、鳥、昆虫、水棲、機械、霊体の10系統。64×64のドット絵を正本とする。
- パーツ：頭、胸コア、尾、肩、背中、翼の6スロット。PLATE / SPIKE / CRYSTAL / RUNEの4スタイル。
- 進化：頭・胸・尾は進化1、肩・背中は進化2、翼は進化3で表示。未解放の装備指定は保存する。
- 属性別のオフラインおすすめ装備と、ユーザーが部位別に指定する手動編集がある。
- 任意の外部AI：ユーザーのGemini APIキーで装備の**スロットとスタイルだけ**を提案。AIに任意のコード・座標・戦闘パラメータを実行させない。
- v2.6ではAIの返答を直接適用せず、**64×64の完成予定画像と6スロットの提案をダイアログ表示**する。承認時のみ捕獲個体の装備を変更する。キャンセルは無変更。
- 途中で戦闘に入ったり、対象が消えた場合、提案を破棄する。承認直前に捕獲個体が変わっていないか再確認する。
- 融合：親Aの頭・胸・肩、親Bの尾・背中・翼を継承。合成前プレビューを表示。
- 画像出力：64×64 PNG、256×256の整数拡大、Glyph用13×13を別々に生成。元画像の13×13直接生成は行わない。

## 未実装・未検証

- AIによる**画像パーツそのものの生成**：現在のAIは安全な既存パーツの選択のみ。任意形状の透過PNGレイヤーをAIが描く仕組みはまだない。
- 10素体×全装備組み合わせの美的品質・シルエット・目の読みやすさの実機評価。
- 実機でのGemini API呼び出し成功と、API利用料金・クォータ。AI利用には外部サービスの利用条件が適用される。
- 既存ゲーム作品の学習データを取り込んだ追加学習はしていない。デザイン上の一般的な原則を参考にするだけ。

## 安全設計

AIの出力は6つの許可済みスロットと4種類の許可済みスタイルに限定。無効な値は拒否。APIキーは端末に保存しない。APIへの送信はボタン操作時のみ。
