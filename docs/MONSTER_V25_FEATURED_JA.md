# Monster Quest v2.5 — 固有ドット絵モンスター「ライゼル」（試作）

## 理由
GitHub Actionsの実描画PNGを目視すると、従来の手続き生成は基本骨格が異なっても共通の稲妻・角・装飾が強く、顔や生物としての特徴が不足していた。自動テストが成功しても美術品質を保証できないことを確認した。

## 試作の固定オリジナル素材
- AI画像生成で作ったオリジナルの雷属性・四足獣「ライゼル」の進化3段階を編集して**64×64のピクセルアート素材**に変換した。
- 各進化段階に固有の頭部・体型・装甲・四肢・尾の形を残す。
- 各画像は**最大15色の不透明色＋透明色**に減色。背景は透過。
- 画素は4bitパレットで圧縮したソース内静的データとして収録する。AI APIのキー・ネット接続は不要。
- `MonsterDesign.sprite`で種族名「ライゼル」かつ属性「雷」なら専用素材を返す。それ以外は従来の10骨格×変種のオフライン生成を維持。
- 通常階層の遭遇候補に「ライゼル」を追加。捕獲後は既存の進化ルールに従って進化できる。
- 個体IDで外見が変わる従来ルールと異なり、ライゼルの固定系統は個体間で同じ固有絵を使用する。カスタムインポート画像が保存されていればそちらを優先する。
- ゲーム本編はネイティブ64×64を256×256にニアレスト拡大。Glyphはこの高解像度正本から必要時だけ13×13へ射影。
- 4コマ待機・3コマ攻撃は従来の手続きアニメーションを利用。手描き差分ではない。

## 検証
- 3段階の64px/4096画素、透明背景、色数、異なる絵であることを単体テスト。
- 全段階でGlyph13×13へ変換でき、物理137LEDの範囲外を点灯させないことをテスト。
- CIのMonsterQuest-PixelArt-Previewに`08-featured-raizel-3-stages.png`を追加。
- 実機の表示バランス・視認性・評価、実際のプレイ操作は未検証。
- 今回は**1種族の試験導入**で、全モンスターの再デザインが終わったわけではない。

## 著作物との関係
ポケモン・デジモン・その他の既存モンスター画像を再配布・学習データ化・模写したものではない。共通する造形原則（形の見分けやすさ、進化での連続性、強いシルエット）を参考にし、独自素材として制作した。
