# Monster Quest v4.6 — 2D横スクロール探索

## 新しい「探索」タブ
- **横スクロール探索が初期モード**。以前のタップ探索に戻るボタンを残し、今までのセーブ（探索の階層、仲間、装備、アイテム、結晶、育成、塔、アリーナ記録）を消しません。
- 方向キー長押しで左右移動。ジャンプ（基本1回）、二段ジャンプ習得後に空中で再度ジャンプ可能。ダッシュ習得後に高速移動できます。落下・着地は重力と足場判定によるもの。
- 画面はプレイヤーを追うカメラでスクロール。元のGBA風64×64モンスターのビットマップをNearest-Neighborで描画。プレイヤーと敵の全身を画面内に収める表示処理（9px余白）と装備を含むアニメーションの描画余白を追加しました。
- トゲ床、敵の時間経過攻撃、攻撃ボタン、敵を弱らせて捕獲、HP回復、相棒と出撃中モンスターの固有スキル／追加スキル。ボス撃破にはこれまでの育成経験値・コイン・ボスドロップが連動。
- 横スクロール用の座標、敵HP、クリア済みエリア、習得能力、休息地点、スキル再使用カウントは、古いセーブに新しい任意フィールド side を追加して保存します。

## メトロイドヴァニアのエリア進行
6つのつながったエリアを往復します。

1. **古びた地下道**：開始地点と休息石。入口付近（xが約2）で「調べる」を押すとHP+20、通常エリアの敵が再出現して捕獲・育成を繰り返せます。
2. **翠影の森**：上段に封印された「天空回廊」の扉。初めて来たときは二段ジャンプがないため届きません。
3. **水没した工房**：右側の遺物を調べると **二段ジャンプ** を恒久取得。この先の封印門はまだダッシュが必要で通れません。
4. **天空回廊**：森に戻って高台へ登り、「調べる」で入ります。右側の遺物を調べると **ダッシュ** を恒久取得。回廊の左端から森へ帰還します。
5. **深淵の門**：工房に戻り、ダッシュ能力を持っていれば右端の扉から進めます。
6. **月蝕の王座**：最後の守護者との戦闘。撃破でボス限定装備の抽選が行われます。王座での再戦は「調べる」で可能です。

探索中は敵の攻撃が時間経過で進行し、左右移動・ジャンプ・ダッシュ・攻撃・捕獲・調べる・回復を操作できます。技能を新たに取得したら、以前通れなかった場所に戻ることができます。

## モンスターの見切れ対策
従来、主に一部のスライム素材で7px余白を使用していました。今後は表示直前に **全モンスター** のアルファ輪郭を9px以上内側に納め、アニメーションで最大1px移動したあと・ボス装備オーバーレイのあとにも最低8px余白を確保します。モデルが元々切れている画像を補う機能ではないため、元画像自体に欠損がある場合は個別の原画修復が必要です。

## 旧データ・既存機能との関係
- タップ探索は削除せず「旧探索に戻る」で再開できます。現在のステージと新しい横スクロールのエリア進行は別々に保存されます。
- 試練の塔・模擬アリーナはこれまでどおり「挑戦」タブにあります。
- 追加スキル・能力抽選・ボス装備・進化・捕獲・合成は従来のデータを保持します。
- 上書きインストールしても既存のアプリデータを失わない設計です。実機のタッチ操作感・グラフィックは、単体テストとCIビルドだけでは保証できません。

## 制限
- 今回は**6エリアの遊べる初期メトロイドヴァニア版**です。大規模なタイルマップエディタ、分岐セーブ、手製の多段ボスAI、オンライン協力プレイはまだありません。
- 既存の画像自体が既に欠けている場合、描画の縮小・余白確保だけでは欠損を戻せません。該当モンスターの実際の表示と元画像を確認して改修します。
