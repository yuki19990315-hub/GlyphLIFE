# Monster Quest v4.8 — ひまつぶクエスト型「進む・戦う・集める」探索

## 研究した参考作品・一次情報
1. **ひまつぶクエスト（moitititi、初代）** — Google Playの公式紹介。右へ進むほど強敵が現れ、レベルと装備で遠くへ進む。進行情報を画面下に表示。コロシアムや組み合わせ装備効果がある。https://play.google.com/store/apps/details?id=jp.pya.tenten.android.himatsubuquest
2. **ひまつぶクエスト（初代）** — 4Gamerの2013年レビュー。画面の右／左を押し続けて移動し、敵と隣接すれば攻撃。死亡で進行をリセットしても経験値・所持金のペナルティなし。倒した敵が仲間になる場合がある。https://www.4gamer.net/games/227/G022753/20130731103/
3. **ひまつぶクエスト＋** — レビューでは上部に横スクロール画面、下半分以上にステータス表示、画面の左右長押しで進行・攻撃できることが説明されている。https://applink.jp/2014062913768.html
4. **Inflation RPG** — Google Play公式紹介。長期的な成長と装備でハイスコアに挑む要素がある。今回の連続討伐ボーナスと個体厳選の報酬ループ設計で、継続して育成したくなる感覚の参考とした。https://play.google.com/store/apps/details?id=air.infurerpgkuesuto
5. **OneBit Adventure** — Google Play公式紹介。進むほど緊張感が増すフロア探索、戦利品、育成ビルドの構造を参考にした。ただし、原作のターン制移動は採用せず、このゲームはリアルタイムで敵が反撃。https://play.google.com/store/apps/details?id=com.GalacticSlice.OneBitAdventure

**実装は完全な独自システム・オリジナル描画です。** 参考作品の画像、キャラクターデザイン、音楽、テキスト、UIアセットの無断転載・複製はしていません。

## 今回の操作
- **左を押す**：歩いている間は後退／通常モンスターとの戦闘中は退却して2歩戻る。ボス戦中は左回避。押し続けると歩行中は後退を繰り返す。
- **右を押す**：すぐ一歩前進／敵がいれば一撃。押し続けると自動で右方向へ進み、近接時には0.39秒間隔で自動攻撃。**攻撃用の追加ボタンを常時押す必要がない**。離せば歩行は停止（敵の攻撃タイマーは停止しない）。
- **選択式の分かれ道**：3階ごとに休息・宝箱・危険な近道。長押しが選択ボタンを勝手に押すことはない。
- **BOSS**：5階ごとに大技を予告。左右回避ボタン、回避成功で弱点が露出し、次の3打が3倍。アクションを複雑にしすぎないためジャンプ・登攀・コリジョン等は入れない。
- **固有/追加スキル**：編成した相棒・モンスターのスキルを個別に選択。普段は閉じておき必要な時だけ展開できる。
- **捕獲**：戦闘中にその時点の成功確率を数値で表示。HPを減らすほど成功しやすい。既存の100匹上限や個体別UUID・育成を保持。**自動捕獲**は初期OFFで、ON時はHP35%以下になった通常敵に対して1回だけ捕獲玉を使用。ボス・満員・捕獲玉なしは対象外。失敗したときは敵の攻撃を受ける。
- **旧タップ操作**：探索画面から任意に切り替え可能。従来の階層・ゴールド・アイテム・HP・スキルは同一セーブ内で共有する。

## モンスター収集＆やりこみの追加機能
- 通常遭遇には**7%で希少個体**が現れる。希少個体はHPが1.5倍、攻撃力が上昇する。捕獲できれば強い基礎値と「rare」の履歴をそのまま保有。画像は既存のGBA風ドット素材を使い、フィールド内の光る縁取りで区別。
- 希少個体を倒すと追加ゴールド・捕獲玉・召喚結晶が入手できる。希少個体を捕まえるか倒すかはプレイヤーの判断。
- **連続討伐チェーン**：退却や戦闘不能で途切れる。**5勝ごと**に捕獲玉+1とボーナスゴールド、**10勝ごと**に召喚結晶+1。通常の入手と戦利品は従来どおり。既にクリアした敵に何度も報酬を発生させることはできない。
- **属性相性**：有利属性の通常攻撃は+25%、不利なら-10%、それ以外は等倍。完全無効を作らず、特定属性がいないことで詰まらない設計。
- **連撃の会心率**：既存の会心率に加えて、同一戦闘のコンボが続くほど会心確率が最大8ポイントまで上昇。
- **個体のお気に入り★登録**：ホームのパーティ画面で個体ごとに★を設定。新着順／高レベル順／潜在値順／希少個体優先でソートでき、お気に入りだけの絞り込みも可能。初期表示は16匹ずつの段階表示にして100匹コレクションのUI負荷を抑える。合成で消えた個体のお気に入りは片づける。潜在値ランキングは現在解放済みの3枠だけを評価し、未解放枠を未来予知していない。
- 従来の**図鑑追跡**（通常遭遇の45%で狙った種族が優先）、固有スキル＋追加スキル、Lv5/15/30の重複可能なランダムステータス3枠、進化、合成、ボス限定装備6種をそのまま使う。

## UI・画像
- **上段：横スクロール風のドットフィールド**。64論理グリッドの背景をプログラム描画し、森・遺跡などフロアで色調と形が変化。進行距離に応じて遠景と前景が違う速度で流れる。
- **下段：RPG情報と大きな2方向ボタン**。HP/EXP、コイン/捕獲玉/召喚結晶/チェーン、戦闘メッセージ、捕獲率、回復、スキル、任意の自動捕獲。縦画面でスクロール可能。
- **モンスターの見切れ防止**：64×64全身スプライトを安全余白に入れて表示。モンスターのアニメとボス装備の見た目は維持。新背景での描画もそれぞれ独立領域にFitで表示。
- フィールド背景・レイアウトは新規実装。ひまつぶクエストの固有キャラクター・アイコン・UI画像を一切コピーしていない。

## セーブ＆継続
- 既存のSharedPreferencesキーとデータ構造を維持。新しいjourneyオブジェクトはオプション項目で旧セーブの読み込みに対応する。
- セーブ保持：捕獲モンスターID、レベル、ランダム能力、装備、図鑑、追跡、探索階層、ベスト階層、ゴールド、石、捕獲玉、塔・アリーナ、素材。
- 攻撃中の大量のセーブ書き込みを避け、敵撃破・被弾・階層移動などの重要イベントはその場で保存し、その他は約0.9秒ごとにチェックポイント保存。
- Android版4.8.0、versionCode 35。

## 現状の制限と継続課題
- モバイルの実機での長押し・画面サイズ・タッチスクロール干渉はAndroidビルド/JUnitとは別途確認が必要。
- BGMやSEは権利的に問題のない自作素材を別工程で追加できるが、今回の公開された音楽素材のコピーはしない。
- モンスターの「元の画像」自体が切れているケースは、表示の余白確保だけでは欠損部分を描き直せない。
- デバッグAPKは旧端末アプリと署名が合わない場合がある。アンインストール前にセーブを保護する。
