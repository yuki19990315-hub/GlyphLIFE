# Glyph Fluid Lab（実装 v0.9）

以前検討していた「Glyphで流体シミュレーション」を、GlyphLIFEの追加モードとして実装。

## 仕様
- Nothing Phone (4a) Proの論理13×13 / 物理137 LEDの円形マスク内を使用。
- 小さな水滴の粒子を重力方向へ動かす、決定的セルオートマトン。
- **厳密な流体力学ソルバーではない**。13×13という低解像度向けの水のような表現。
- 再生/一時停止、粒子追加、手描き追加/消去、重力4方向、80～500ms更新。
- 「背面に出力」を選んだ場合に限り、前景アプリから公式SDKアダプタへフレーム送信。
- SDKなしAPKではスマホ画面でのみ動作。
- 現在の粒子配置をGlyph Creatorの選択フレームへコピー可能。上書き前に確認する。
- セルが物理LED対象範囲外に移動しないこと、粒子数保存則などをユニットテストで確認。

## 未実装/未検証
- 実機での背面LED表示、SDK接続制限、最大安定FPS、電池持ち。
- 加速度センサーによる傾斜操作、NFCリング連動。
- 粒子間圧力や粘性などの本格的な流体数値計算。
