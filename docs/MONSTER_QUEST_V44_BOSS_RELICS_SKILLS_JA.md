# Monster Quest v4.4 — ボス限定装備＋固有スキル

## ボスドロップ
探検（5FごとのBOSS）と試練の塔（5 / 10 / 15 / 20Fの守護者）で、撃破時に35%の確率で装備品が1つドロップします。3回連続で外れたら4回目のボス撃破で必ず1つ獲得します。非ボス・アリーナ・戦闘離脱ではドロップしません。上限は80個。

ボスの属性に応じて65%でテーマ装備、35%で装備カタログからランダムに選択します。受け取った装備は別々のIDを持ち、重複装着できません。

| 装備 | 効果 |
|---|---|
| 月蝕の牙 | 攻撃+6 |
| 雷機の歯車 | 会心率+8% |
| 星護の印章 | 受けるダメージ-4 |
| 深淵の核 | 攻撃+4、防御+2 |
| 生命の珠 | 勝利後HP+8 |
| 秘術の時計 | 固有スキルの再使用カウントを早める |

## 装着
ホーム →「装備」→「ボス限定装備」で相棒または所持仲間を選び、装備品の「装着」を押してください。1体に1個装備できます。装備の移動、解除も可能です。戦闘時に効果が出るのは相棒と出撃パーティ（最大3匹）の装備だけ。控えの装備は効果が出ません。戦闘中は変更不可。合成で親を消費すると装備アイテムは残り、着用だけ解除します。

## 固有スキル
相棒と編成中の仲間は、それぞれ体型・属性・種族から決まる固有スキルを持ちます。探検・塔・アリーナの戦闘中、攻撃ボタンの下にある各モンスターのスキルボタンを押して発動してください。

| モンスターの例 | スキル効果 |
|---|---|
| ルナ（光） | 月光の祈り：HP回復 |
| ライゼル | 迅雷の双牙：連撃＋敵攻撃遅延 |
| ドラゴン | 竜炎ブレス：高威力攻撃 |
| ゴーレム | 結晶障壁：次の敵攻撃を70%軽減 |
| 精霊 | 精霊の癒し：HP回復 |
| 闇の精霊 | 影吸収：攻撃＋回復 |
| 機械 | 雷機砲：攻撃＋敵の行動遅延 |
| 水生 | 渦潮弾：攻撃＋行動遅延 |
| 飛行・鳥型 | 疾風斬：大ダメージ |
| 虫型 | 猛毒針：次の通常攻撃2回に追加毒ダメージ |
| スライム | 粘液の鎧：次の敵攻撃を大幅に軽減 |

使用後はモンスターごとに再使用までの回数が表示され、通常攻撃を重ねると再使用可能になります。スキルを押すだけでは残り回数は減りません。ボスをスキルで倒しても通常と同じ撃破報酬を獲得できます。

## 永続データと互換性
既存のセーブ名 monsterquest_v41_clean を維持。bossRelics・relicEquipment・relicDryBosses と戦闘ごとの skillCooldowns・guardHits・venomCharges を追加します。旧セーブの仲間・画像・レベル・アイテム・塔・アリーナの記録を保ち、追加項目には安全な初期値を適用します。重複した装備参照はロード時に除外します。

## 注意
ボス限定装備は戦闘用であり、従来のドット絵アーマー工房とは別のアイテムです。モンスターの見た目や画像ファイルを自動で変更する仕様ではありません。実機の操作感は未検証で、ドロップ率・威力は初期バランスです。
