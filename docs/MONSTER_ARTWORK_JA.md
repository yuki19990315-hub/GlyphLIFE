# Monster Quest v0.5 — 高精細モンスター立ち絵

**問題:** 以前のAI生成は「cute」重視の文章プロンプトと、白黒13×13ドットだけを画像としていたため、複雑な鎧・角・翼・複数色を表現できなかった。

## 新しい構成

- **ゲーム画面の高精細立ち絵**と**背面Glyph用13×13ドット絵**を分離。
- AI設定生成のプロンプトはかわいいマスコット路線から、重厚な幻獣・メカ・クリーチャーを重視する指示へ変更。
- 戦闘中に**立ち絵をAI生成**を押すと、別のGemini画像生成API（`gemini-3.1-flash-image`）に依頼する。
- デザインの方向性は「ダークファンタジー」「メカ・機甲」「竜・幻獣」「神秘・神獣」から選択。全身、複数色、複雑な材質、印象的なシルエットを要求。
- 画像は1K / 縦3:4、文字や透かしを要求せず、ゲーム図鑑向け1体のオリジナルキャラ画像を依頼。
- 画像生成は**別の有料APIリクエスト**。自動では実行せず、ユーザーが明示的に押した時だけ送る。
- AI生成を使わず、ユーザー自身が作ったイラストをAndroidの画像選択から取り込むこともできる。
- 読み込み・生成した画像は端末のアプリ専用領域にJPEGとして最大1100px程度に縮小保存し、Monster Questの敵個体IDにひも付ける。
- バトルと捕獲図鑑のプレビューに高精細画像を表示し、画像がなければ旧13×13表示へフォールバックする。
- 13×13のGlyphドット絵は既存の別フィールドとして保持し、画像生成の成否で破壊しない。
- APIキーは実行メモリのみ。保存しない。
- 既存画像は新しい画像の保存成功まで維持する。

## 料金・プライバシー

Google Gemini API公式価格（2026-11-12確認）では、`gemini-3.1-flash-image`のAPI**無料枠は利用不可**、1K画像1枚の出力費用は約**$0.067**で、別途テキスト入力料金などがある。金額は随時変更され得る。

- https://ai.google.dev/gemini-api/docs/pricing?hl=ja
- https://ai.google.dev/gemini-api/docs/generate-content/image-generation

画像生成時にはモンスター名・属性・説明・選んだデザイン方向性をGoogleへ送信。手持ち画像の読み込みは端末内処理であり送信しない。実機・実通信による画像品質の検証は未完了。

## 今後の高品質化
- 1体につき複数案を並べて選ぶ。1回の生成だけで満足できる保証はないため、追加課金の明示が必要。
- 高精細の初期・進化・融合形態を同一デザインで整合させるため、参照画像を使う追加生成。
- 背景透過と体パーツごとのアニメーション素材分離。現在の高精細立ち絵は静止画のみ。
