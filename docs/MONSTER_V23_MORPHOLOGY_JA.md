# Monster Quest v2.3 — 個体差のある64×64モンスター造形

## 実装の基礎
- **64×64ネイティブドット絵**がゲーム画面の正本。
- **256×256図鑑**は64×64のニアレストネイバー4倍拡大。256pxの追加ディテールを自動で創出するわけではない。
- **13×13 Glyph**は64×64の色・透過・形状からオンデマンドで生成する派生素材。137個の物理LEDマスクを適用。
- AI画像生成は任意の外部有料APIで、通常のオフライン生成とは別。外部APIなしでも64pxのオリジナルモンスターを生成可能。

## 新たな造形差分
同じ基本骨格（四足獣・竜・二足・巨像・蛇・鳥・昆虫・水棲・機械・霊体）でも、個体ごとに追加の形状が変わる。
1. 前方に広がる二股の角
2. 背中の連続装甲棘
3. 大型肩装甲と中央発光部
4. 二枚刃の尾・ヒレ
5. 湾曲した角と頬の棘
6. 非対称の冠と長い背中の刃

さらに額の紋様は分岐角・結晶・バイザーの3系統。
- 見た目の差はシルエット（透明/不透明の輪郭）に表れ、色替えだけではない。
- 個体ID・種族名・属性・系譜を使った決定的な種により、同じ個体は再生成時に同じ造形となる。
- 進化でstageが変わっても造形の核は変わらず、装甲や装飾が追加される。
- 上位の形状パーツが顔や胴体を一部覆う場合があるため、完成品質は実機表示・目視評価が必要。

## 品質保証
- 同一体型36個体でシルエットの差異を単体テスト。
- 64×64画素、16色以下、13×13の物理LEDマスク遵守、決定的生成、進化差分を確認するテスト。
- GitHub Actionsのビルド・ユニットテストが成功してからmainへ反映する。

## 次の品質課題
- 本格的な手描き風ピクセルアートの品質には、骨格別の輪郭、部位ごとの立体感、非対称の重心、攻撃/待機ポーズなどのアートディレクションが必要。
- 64×64からの単純な13×13縮小では顔が潰れることがある。輪郭と目・角を優先する専用の補正を追加する。
- 融合時に親の体パーツや装飾をより厳密に継承する仕組みが必要。
- 既存IPからは抽象的なシルエット、配色、進化の一貫性などの技法を参考にし、特定キャラの模写・素材転用・モデルの追加学習は行わない。
