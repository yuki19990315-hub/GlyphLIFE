# Monster Quest v4.0 — 4タブ・タップ探索と召喚

## UI
画面下に「ホーム／探索／召喚／？」の4タブを固定。「？」はタップ可能だが未開放、今後のアップデート予定と表示する。

- **ホーム**：相棒・プレイヤーHP・最高到達階、召喚結晶／捕獲玉／回復薬、ゴールド、最大3匹のパーティ編成、図鑑一覧、従来の研究所（装備、画像パーツ、進化、合成、Glyph全身変換）を配置。
- **探索**：森林・遺跡・結晶洞窟のドット背景、64×64のモンスター素材を拡大表示。フィールドと大きな「タップ」ボタンはどちらも同じ操作。敵がいなければ1歩進み、出現中なら1タップ＝1攻撃。
- **召喚**：召喚結晶1個を消費。オフラインランダム召喚はAIではない。Gemini APIを利用する場合は名前・属性・体型をAIで作成し、ビジュアルはローカル64×64素材を使用する。画像そのもののAI生成は別チェックボックスで明示的に選択した場合のみ実施（API利用料金に注意）。
- **未開放**：現時点では操作しない予定エリア。

## 探索ルール
- フロアごとに7歩。2歩目以降、各タップで27%の確率で敵が出る。出現した敵との戦闘中は歩数は増えない。
- 敵は3連打ごとに反撃する。与ダメージは相棒レベル、編成した仲間の攻撃力、会心によって増加。連打してもサーバー同期などは行わない。
- 捕獲玉を使った敵の捕獲は敵HPが減るほど成功率アップ（最大85%）。捕獲玉は消費し、失敗時に反撃ダメージを受ける。ボスは捕獲不可。
- 通常の敵撃破時、8%の確率で召喚結晶を1個入手。通常フロア完走でも5%で追加ドロップ。
- **3Fごとに分岐**。休息はHP+28、宝箱は捕獲玉・コインと40%の結晶、危険な道は70%で敵・それ以外は結晶を入手。
- **5Fごとにボス**。7歩目で固定出現。高HP・高攻撃力、HP半減で攻撃間隔が短縮。大技が飛ぶ側を表示し、左右移動で反対側に逃げると回避成功。3回の弱点攻撃が3倍威力。撃破で結晶2個、次フロアへ。
- 戦闘不能で**探索を1Fからやり直し**、HP100、回復薬最低1個。編成・捕獲・図鑑・結晶・捕獲玉・コイン・最高到達階は保持。

## 召喚とAI図鑑
- 結晶1個で新たな仲間を作り、捕獲リスト＋図鑑へ登録（100匹の所持上限）。
- AIで作ったモンスターの `lineage=ai-summoned` を識別し、今後の一般戦で22%の候補枠に設定（毎タップの出現確率ではない）。
- 元のAI生成ビジュアルの所有者IDを `artSourceId` に保持。新しく出現した同種モンスターは**個体IDを別にしつつ**保存済み画像を参照し、見た目が名前だけの別物にならないようにする。
- 外部画像生成の結果は64×64グリッド、透過込み16色へ取り込み時に正規化する。公式IPのキャラクターを再現する機能ではない。

## セーブ互換性
既存の `monsterquest_v1` SharedPreferences に新しい `tapRun`, `summonStones`, `captureOrbs`, `catalog`, `partyIds` を任意項目として追加。古いセーブにない場合は1F・結晶0・捕獲玉3・空図鑑・空パーティから開始。既存の捕獲・装備・Glyph連携・画像ファイルはそのまま保持する。

## 今後の改善候補と既知の制約
- 背景は実装内Canvasで描くGBA風の森林／遺跡／洞窟。画像モックアップと完全に同一の見た目ではない。
- スマホでの視認性、実機の高速連打、Glyphの物理LEDの輝度は未検証。
- 同種のAI画像は登録元と再出現時で共有するが、元画像が削除された場合は通常のローカルスプライトへフォールバックする。
- ボスの攻撃はタイマー式でなく**攻撃タップ数に応じる予告式**。将来のテンポ調整、ボス専用モーション、回避無敵などは別途設計可能。
- 暇つぶしクエストの著作物や画面を複製せず、「タップで前進・タップ連打で攻撃」という操作感を参考にしたオリジナルUIとする。
