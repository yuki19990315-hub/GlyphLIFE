# 手続き的配合 DNA v1

## 参考・独自実装の区別
- RujiK の GameMaker インタビュー: https://gamemaker.io/en/blog/socket-beast-rujik
  身体特徴の数値化と線形補間による配合を参考にした。
- 開発者動画: https://www.youtube.com/watch?v=ohYIUxmxI-I
- 生成ルール動画: https://www.youtube.com/watch?v=j9IEhJnh0Bw
- Critter Crosser のソースコードは使用していない。本実装は Kotlin の独自実装。
  原作の3D生成やIKを再現したものではない。

## 既存との差分
配合のプレビューと確定で同じ DNA を生成。親の数値を補間し、脚ペア数などを制限、
低頻度の突然変異を適用する。13個の形質（胴体長、厚み、姿勢、脚ペア数、脚長、
首、鼻口、尾、翼、角、装甲模様、基調色、差し色）と個体差 seed を保存する。
既存個体は10種の体型テンプレートから初期DNAに変換する（元画像から推定はしない）。
子孫は保存されたDNAを継承し、再配合できる。有限の形質空間なので全個体の外観が
絶対に一意とは保証しない。

新規配合個体の64x64ピクセル絵を整数座標・接続点・多角形から生成する。
標準装甲の接続点も身体座標に追従。既存のカスタムPNG装甲・ユーザー画像優先は維持。
アニメーションはマスター画像の行変形による低コストの動きで、既存Glyph表示と
同じ全身13x13輝度投影を使う。専用の関節IK、実機での見栄え、カスタム装甲の
自動再配置は今後の課題。戦闘能力、捕獲、進行、配合素材消費の既存仕様は維持。

## 永続化
designSeed の dna1: 接頭辞でのみ有効化。既存の64文字制限内で完結する。
旧セーブ・旧配合個体・既存の工房・固定アートは変更しない。破損値は通常描画へ戻す。

## 検証
CreatureDnaTest: 全10×10体型、反復配合、プレビュー・確定ID変更への耐性、
64px品質規格、フレームとGlyphマスク、破損DNA。
Android CIは既存 android.yml で単体テストとAPKをビルドする。

## 第2段階（PR内更新）
- 2リンクの膝計算、脚の位相差、翼・尾・前肢の個別動作、攻撃姿勢。自作画像や装甲付き個体は既存の画像変形を維持。原作の完全な物理IKではなく、2D座標での限定的IK。
- 多角形装甲、背面プレート、翼の筋、顎、直立体の腕。輪郭の最大8近傍成分を保持し、サイズ・色・連結率を評価。4候補から機械的評価で選ぶ。美的完成度は実画像の確認が必要。
- DNAから移動タイプと既存スキルを選択し、HP・攻撃・スキル威力に上限付きの補正。既存個体は旧スキル規則のまま。戦闘システム自体は変更しない。
- 冒険画面に歩行・HP変化からの攻撃アニメーションを接続。10系統のモーション比較PNGを既存CIのプレビュー成果物に追加。
- カスタムPNGの関節変形、自動装甲リターゲット、実機視覚評価は未対応。

## 装甲追従の追加
生成個体の標準装甲とカスタムPNGをアニメーションの接続点に追従させる。PNGは剛体の部品として移動し、画像内部のメッシュ変形はしない。手動オフセットは保持し、生成個体の配置は枠内に収める。別途インポートした全身画像は従来の画像変形を維持する。冒険画面とスプライトシート出力で同じフレーム解決を使用する。実機上の見栄えは未検証。
