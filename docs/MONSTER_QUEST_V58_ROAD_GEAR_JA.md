# Monster Quest v5.8 — 操作配置と武器・防具の連携

## 今回実装する内容

- 探索下部の移動領域を3等分。左1/3が後退、中央1/3が奥義、右1/3が前進・接近自動攻撃。左右はタップ／長押しに対応。
- 移動領域の**上**に捕獲・回復・技の3ボタンを配置。捕獲玉と回復薬の使用ルールは維持。
- 主人公用の武器と防具を各1つ装備できるようにした。初期装備は無料、追加装備はホーム→装備からゲーム内Gで購入する。
- 5種の組み合わせがあり、**1セットにつき2種類のパッシブスキル**が発動。攻撃・防御・会心・通常攻撃での技クールダウン短縮・戦闘勝利時回復に実際に加算される。
- 購入済み装備と装着中の武器・防具をローカルセーブへ保存。旧セーブは初期装備で継続する。
- 既存のボス装備・固有スキル・捕獲・回復の機能は維持する。

## 対応しないもの

- ①「戦闘距離連動の新ルールとHPの自然回復」は追加しない。既存の左右移動・間合いルールは維持。
- ④「ペットが独立して攻撃する新機能」は追加しない。既存の仲間のステータス援護は維持。
- ⑤道中施設、原作型ダンジョン、宝箱の追加は保留。

この実装は公式公開情報で確認できた「装備の組み合わせで複数スキルが発動する」という**ゲーム性の着想**に基づくオリジナル仕様。原作の装備名・組み合わせ表・内部計算式・画像データの完全再現ではない。
