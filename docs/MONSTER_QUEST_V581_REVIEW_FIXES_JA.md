# Monster Quest v5.8.1 レビュー修正

## 修正済み

- **試練中の探索操作**：試練の塔・アリーナ中は、探索画面側の捕獲・回復・技・奥義・自動捕獲切り替えを無効化。操作入口だけでなく、探索ロジック側でも捕獲・技・回復・切り替えを拒否する。
- **バックグラウンドの戦闘進行**：Activity が停止したら探索・旧式戦闘・試練の各100msタイマーを停止し、長押し移動も解除する。復帰時に押しっぱなしを再開せず、プレイヤーが再び操作してから歩く。
- **直前の進行保存**：バックグラウンド移行時と画面の破棄時に最新のゲーム状態を同期保存する。連打中の定期チェックポイントに含まれなかった状態も保存対象となる。
- **回帰テスト**：試練中に捕獲玉・回復薬・奥義ゲージを消費せず探索が進まないことをモデルのユニットテストで確認する。

## 対象外・未検証

- 実機でのタッチ領域、多指操作、OSによる強制終了時のすべてのタイミングは未検証。
- 前版とのAPK署名一致はこの修正と無関係であり、別途確認が必要。上書きインストール失敗時にアプリを削除すると保存データが失われ得る。
- 保留とした新規道中施設・原作型ダンジョン・宝箱の追加は行っていない。
