# Glyph Toy 時計＋バッテリー表示（実装 v0.12）

## 表示仕様
- Nothing Phone (4a) Proの物理LED137点のみを利用した13×13プレビュー。
- 画面上段（y=1..5）: 24時間制の時（HH）、下段（y=7..11）: 分（MM）。
- 中央に時刻のセパレーター、最下段（y=12）にバッテリー残量の5段階LEDゲージ。
- OSの時計とstickyバッテリーステータスを使用。ネット接続・GPS・追加の危険な権限は不要。
- GlyphLIFEの「連携」タブでAOD Toyを**ペット**または**時計・バッテリー**から選択。
- 選択した内容は端末内に保存。スマホの画面で現在時刻をプレビューし、任意で前景Glyphへ転送できる。
- AOD Toy側はNothing OSの`EVENT_AOD`を受けた時に時刻と電池残量を読み直す。
- AOD Glyph Toyは約1分ごとの更新であるため、秒針や滑らかな時計アニメーションは実装しない。

## 留意点
- 公式Nothing Glyph Matrix SDKを組み込んだローカルAPKが必要。GitHub ActionsのSDKなしAPKでは画面側だけ表示できる。
- Glyph ToyをNothing OSのシステム設定で選択する必要がある。
- 背面実表示、Flip to Glyph、画面消灯時のシステム優先順位、更新間隔は端末で未検証。
- バッテリー取得に失敗するとゲージは空になる可能性がある。電池残量の正確性は要実機確認。
