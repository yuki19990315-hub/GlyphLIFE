# Monster Quest v5.9.0 — 探索画面の立て直し（第1段階）

ユーザーから「ひまつぶクエスト＋と似ても似つかない」という実機フィードバックを受け、
新機能追加を止め、探索画面を操作感優先で再設計する。

## 変更点

- 探索中は下部ナビゲーションを隠し、フィールド描画面積を拡大。
- 画面上部にモンスターHP、歩行距離、所持金、エリアの必要情報のみ表示。
- 下部約1/3を操作領域に固定。最下段に左右の長押し操作、ひとつ上に捕獲・回復。
- 戦闘接触、右長押しによる自動攻撃、連打による追加攻撃、左後退は既存の一本道ルールを維持。
- 奥義、個体スキル、ステータス振分、補給、旧探索画面への比較切替は「メニュー」に集約。
- 主人公は引き続きユーザーが選んだメインモンスター。敵は左向き。
- キャラクター・捕獲個体・進行状況の永続化形式は変更しない。
- Monster Questアクティビティを横画面表示に指定。

## 次の実機比較で必ず確認

1. 右長押しで連続前進すること、敵に接触して止まり自動攻撃すること。
2. 右連打で攻撃が速くなること。左長押しで敵から離れられること。
3. 捕獲・回復は手を離して単独で押せ、ゲーム内資源が正しく減ること。
4. 小型・大型端末の全幅で、キャラクターが見切れず、道と遠景を認識できること。
5. メニューからホームへ戻り、再開後に同じ位置・所持品が復元されること。
6. 新APKが既存のセーブを維持して更新できること（別署名のデバッグAPKは上書き不可）。

この版は操作画面の初回再構成であり、原作との実機並走比較をまだ実施していない。
原作そのものの完全再現や遊び心地の同等性を主張しない。
