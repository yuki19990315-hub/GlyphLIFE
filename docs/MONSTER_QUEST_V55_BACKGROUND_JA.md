# Monster Quest v5.5 — 10エリア×4層のスクロール背景

## 基本設計

承認済みの縦型ゲームUIは維持し、**横長の探索ステージ部分**を16:9の論理フィールドに統一。固定の背景1枚ではなく、64×64キャラクタースプライトと同じ粗密感を意識した、ピクセルグリッドに沿う背景システムへ変更。

- 基準フィールド：320×180ピクセル（16:9）
- ループ用の各レイヤー：640×180ピクセル
- タイル・地面の基本単位：16×16ピクセル
- オブジェクト：概ね32〜64ピクセル（樹木、柱、岩、結晶）
- 形式：背景遠景PNG、透過中景PNG、透過床PNG、透過前景PNG
- 色数：各エリアの合算で32〜64色に制限
- 描画：整数倍スケーリング + `FilterQuality.None`、ぼかし・アンチエイリアスなし
- 画面比率が異なるときは等倍率で描画して中央をクロップし、縦横比を変えない
- ループ再生は同じレイヤーを境界で再描画（ビューに隙間を作らない）

## エリア

| 連続探索エリア | 基本演出 |
|---|---|
| 草原 | 遠い丘、柵、若木、草の地面 |
| 森林 | 濃淡2種の樹木、倒木、キノコ、微かな雨 |
| 洞窟 | 鍾乳石、青い結晶、発光鉱石 |
| 古代遺跡 | 柱列、石の梁、松明、石畳 |
| 火山 | 噴火口、溶岩の流れ、火の粉 |
| 雪山・氷洞 | 遠い尖峰、氷柱、雪粒 |
| 海岸 | 海の地平線、ヤシ、帆、波紋 |
| 荒野 | テーブル状の岩山、枯木、岩、骨 |
| 闇の迷宮 | 暗い柱、崩れた建造物、紫の灯火 |

通常エリアは2階層ずつ移り、18階層で一巡して繰り返す。ボス戦になると通常エリアを問わず専用祭壇へ切り替わる。

## レイヤー速度

距離を1としたときの背景移動係数：遠景0.18／中景0.48／地面1.00／前景1.25。

地面はゲーム描画領域の **約79%** の高さに設定し、キャラクタースプライトの接地座標と一致。前景オブジェクトは主に画面下端に配置し、攻撃予告の中央エリアは透過する。弾幕は前景よりも手前に描画。

## 生成・検証

- `python3 scripts/generate_monsterquest_backgrounds.py`：40個のオリジナルPNGを再作成。
- `python3 scripts/check_monsterquest_backgrounds.py`：PNGサイズ・透過領域・32〜64色パレット・スクロール3地点を検証し、`docs/MONSTER_QUEST_BACKGROUND_QA.png` を出力。
- `PixelBackdropAssetTest`：実際にAPKへ含めるリソース40個を対象とするJVMテスト。
- `PixelBiomeRulesTest`：エリア割当、スクロール速度、各画面幅に対する整数スケールの検証。
- GitHub Actions の `[ui-qa]` 付きコミットは Android Emulator の実スクリーンショットも取得する。成功したビルドとその画像でアプリ内の見え方を再確認する。

### 残る実機検証

生成コードを使った再構成ドット絵のため、アセット品質は検証プレビューで確認できても、ゲーム上の移動アニメーション／文字とステージの重なり／実際の指での操作感が自動的に保証されるわけではない。Nothing Phone (4a) Proの実機については、ユーザー側での最終確認が必要。素材は今後もピクセル単位で修正できる。
