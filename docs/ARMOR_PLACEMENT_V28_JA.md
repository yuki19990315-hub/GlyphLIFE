# Monster Quest v2.8 — カスタム画像パーツの位置・サイズ調整

## 仕様

AI画像生成や外部PNGの取り込みから作られるカスタム装備は、変更しない元の64×64透過PNG（UUIDで保存）と、個体ごとに独立した装着設定で管理する。

- X / Y: 素体ごとの初期アンカーから -12〜+12 ピクセル。上下左右ボタンで1ピクセルずつ調整。
- サイズ: 50〜150%。10%刻みで変更。極端な巨大化・画像の切れ・隠れを減らすための安全な範囲。
- 調整値は `WildMonster.partPlacements` にスロット別で保持し、保存ファイルの `partPlacements` に格納。元画像には非破壊。
- 旧保存データに設定がない場合は X=0, Y=0, サイズ100% を使い従来の見た目を維持。
- 画像パーツの解除・差し替え時には該当部位の調整設定をクリア。
- 融合前のプレビューも端末に保存された画像を読み込んで表示。融合後は親A（頭・胸・肩）と親B（尾・背・翼）の装備画像IDと対応する位置設定を継承。
- 進化で装備解放前の部位は変更なし。AI生成・PNG取り込み時の確認画面では、解放後の進化段階の外見を表示して確認可能。
- 戦闘/待機アニメ、64px/256px出力、Glyphへの13×13変換には同じ合成済み64px画像を利用する。
- 許可された6スロット以外・サイズ・座標の範囲外は検証で拒否。

## ステータス

コード上の機能と単体テストを追加。GitHub Actions成功時のみ確認済みと記載する。Google画像生成APIの実通信、Nothing Phone (4a) Pro実機、描画の見た目は未検証。
