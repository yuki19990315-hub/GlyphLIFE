# 新機能: エフェクト工房 & モンスター合成

2026-11-12 / GlyphLIFE v0.11 / Monster Quest v0.4

## GlyphLIFE: エフェクト工房
- Creator画面内に「エフェクトを作る」ボタン。
- 7種のオフライン生成: 雨、星空、ハート鼓動、炎、波紋、レーダー、流星。
- 12/16/24/32コマ、100～600ms速度、再生成用のシード切り替え。
- すべて物理137LEDマスクに準拠、最大64コマ制限内。
- 作成中は独立したアニメーションプレビュー。元データは変更しない。
- 「Creatorに読み込む」は元データ上書きの確認ダイアログを出し、既存のUndo履歴にも追加。
- 「作品として保存」は編集中のデータを変更せず、最大30件の作品ギャラリーへ名前付きで保存。
- 背面Glyph表示は既存の公式SDK対応ビルドと接続機能を利用。SDKなしAPKではスマホ画面のみ。
- 実機のLED再生品質、消費電力は未検証。

## Monster Quest: モンスター研究所
- 捕獲した仲間を図鑑として表示。属性別13×13ドット絵プレビュー。
- 合成では素材Aと素材Bの**異なる2匹を消費**して新種1匹を生成。
- 合成の名前、属性、能力値、ドット絵の継承は決定的なルールに従う。AIやネット接続は不要。
- 同じ属性なら維持。火＋水、光＋闇の相反組合せは「無」属性。その他は固定優先順位で決定。
- 合成モンスターのHP/攻撃は上限あり（HP180 / 攻撃40）。素材のAI生成値をそのまま採用しない。
- 合成前には最終確認を表示。戦闘中や同じ素材を2回使う合成を拒否。
- 合成後のコレクションはQuestStorageの保存データに永続化。コレクションは最大100匹。

## Monster Quest: 援護攻撃
- 過去に捕獲した**最後の1匹**が1戦に1回だけ援護できる。
- 援護の属性と攻撃力はゲーム側の数値で計算。属性有利ならダメージ増加。
- 援護で倒し切れない場合は敵の反撃。戦闘終了後、次の階層で再度使用可能。
- 援護使用済みフラグは保存され、アプリ再起動で無制限使用にならないようにする。
- 合成して強化した仲間も援護に参加できる。
