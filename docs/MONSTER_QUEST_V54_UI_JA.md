# Monster Quest v5.4: 探索・ボス戦デザイン

## 探索UI

- 夜の森の遺跡を描くオリジナル背景画像 `mq_forest_ruins.png` を、64×64の生き物スプライトとは分離して表示。
- ボス戦だけ月夜の遺跡 `mq_moon_ruins.png` に切り替え。
- 画面上に金縁の冒険ヘッダー、階層、距離、所持金、召喚結晶を設置。
- ドット絵舞台内に敵の名前・HPを重ね、下部に主人公のHP・仲間の経験値を固定表示。
- 戦闘外ステータス・商人・捕獲自動化・技の詳細は縦スクロール。操作ボタンが画面外へ押し出されない構成。
- 最下部の「ホーム／探検／召喚／挑戦」ナビも同じ配色・金縁の選択表示に変更。

## ボス戦の移動と攻撃

- **後退（左）／攻撃（中央）／前進（右）** の3ボタン。
- ボス戦の左右ボタンは攻撃せず、位置だけを連続移動。ボタンを長押しすると自動で繰り返す。
- 左右で移動するたびにキャラが自動でぴょんぴょん跳ねる。独立したジャンプボタンは存在しない。
- 攻撃は一定距離まで近づいたら中央ボタンから実行。範囲外では攻撃ボタンを無効化。
- 弾幕の着弾位置・空中判定・回避による弱点露出と奥義チャージは既存システムを維持。
- 通常戦闘の右長押し連撃と退却はそのまま使える。通常時も中央の攻撃ボタンで単発攻撃可能。

## ドット絵の見切れ対策

- 既存の `MonsterArtworkView` の64×64キャンバス内フィットと8ドット余白を維持。
- 探索・ボスのキャラ表示枠は正方形を保ち、拡大時は nearest-neighbour を使用。
- キャラの足元を背景の地面（画面高約79%）へ揃える。ボスは敵キャラの全身と攻撃範囲を見せる。
- アセット再生成で元素材の切り落としが生じているケースは、画像ビュー側だけでは復元できないため、元画像の差し替えが必要。

> v5.5からは背景用の一枚絵を撤去し、[10エリア×4層のタイル背景](MONSTER_QUEST_V55_BACKGROUND_JA.md)に置き換えた。
