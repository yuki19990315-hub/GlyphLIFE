# Monster Quest v4.3 — 試練の塔／模擬アリーナ

## 追加した場所
画面下の4つ目のタブが、従来の「？」（未開放）から **「挑戦」** に変わります。ホーム、探検、召喚はそのまま。モンスターは既存の64×64素材を使用し、味方を右向き・敵を左向きに表示します。

## 試練の塔（オフライン）
- 1階から20階まで連続勝ち抜き。階数が進むと敵のHP/攻撃が上昇し、5/10/15/20階に守護者が出現。
- 1階ごとに経験値とコインを獲得、勝利後は挑戦HPを16回復して次の敵へ。途中のHP・守護障壁は次の階にも引き継ぐ（障壁の使用状態はリセット）。
- 5F初回突破：結晶2個、10F：3個、15F：4個、20F：6個。**各階の初回だけ**。再挑戦の通常経験値・コインは獲得可能。
- 20F踏破でクリア回数を記録。敗北・自分から帰還すると今回の挑戦は終わり、次回は1Fから。
- 最高踏破階、初回報酬受取済み、完全踏破回数は永続保存。

## 模擬アリーナ（オフラインPvE）
- **実際の対人戦ではありません**。NPCモンスター3体の連続戦（3ウェーブ）。育成済み相棒とホームで出撃編成した最大3匹のステータスが攻撃力に反映されます。
- 3連勝で勝利。HPはウェーブ間で12回復、勝利でレート上昇（連勝ボーナス有）、敗北でレート低下。途中棄権も敗北扱い、軽めの減点。
- ランク：ブロンズ（1000〜）、シルバー（1200〜）、ゴールド（1450〜）、プラチナ（1750〜）、マスター（2100〜）。初めてそのレート帯へ到達した際のみ追加の結晶（1/2/3/5個）。
- ランクが下がっても最高到達レートは残り、同じ昇格報酬を再度受け取ることはできません。
- 探検とは別のHP100から開始。模擬戦中に探検の本編HPが減ることはありません。

## 共通戦闘・成長
- 画面タップか大きい攻撃ボタンで攻撃。**敵の反撃は独立タイマー**（連打数に比例しない）。
- 「守護障壁」は次の攻撃を1/4程度に軽減、9秒のクールダウン。ボスのタメ攻撃にも使用可能。
- 挑戦タブを閉じると戦闘タイマーを停止し、戻ると再開。戦闘状態はセーブされ、アプリ再起動後も再開可能。
- 戦闘で相棒と出撃仲間に経験値、個別出撃勝利数。育成、進化、恒久攻防強化、装備が反映されます。
- 塔/アリーナの実績6個（塔5/10/20、アリーナ3勝/10勝/ゴールド到達）を育成タブに追加。全実績は一度だけ受領。
- **同時に複数の戦闘を進行できない**ように、挑戦中は通常の探検と編成変更・召喚を一時停止。挑戦が終わると再開。
