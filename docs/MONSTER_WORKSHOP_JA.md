# AIモンスター工房：一発召喚と誕生条件の図鑑記録

## 決定した仕様
- 文章・写真で条件を入力 → **AIで1回生成** → 成功した1体をそのまま召喚 → 図鑑に誕生条件を記録。
- 同じ召喚に対する再生成・最大4案の比較・採用／不採用ボタンを撤去。
- 画像生成と内部での加工が成功すると、召喚結晶を1個消費して仲間・図鑑へ即登録する。
- エラー時は召喚結晶を消費せず、ゲーム内の仲間・図鑑を変更しない。
- 召喚成功後は結果プレビューのみ表示。閉じるボタンは取り消しではない。

## 図鑑の誕生条件
- AI召喚：入力した文章・写真利用の有無・属性・体型・主モチーフ・副モチーフ・画像AIの使用有無。
- 合成：素材2体の名前・属性・進化段階・2体合成ルール。
- 図鑑の各カードに「誕生条件」ボタンを設置し、保存された情報を確認できる。
- 通常出現や旧データで生成条件が保存されていない場合は推測せず「記録なし」と表示する。
- 以前と同じ種族名・属性の場合は図鑑で最初の記録を維持。全個体の履歴ではない。
- 既存QuestStorage JSONへ任意フィールドとして追加し、旧セーブでも読み込める。

## 画像規格と制約
- GBA風64×64、透過色含め最大16色、手足・翼・角・尻尾を見切らせない。
- 画像生成OFFは従来の仮素材であり、AIが絵を描いた結果ではない。
- GbaMonsterArtStandard.auditは画像サイズ・透過・色数・端接触だけを検査する。美観やAIっぽさの除去までは自動保証しない。
- AIの画像モデルへの依頼はユーザーが明示的に生成ボタンを押した時だけ実行し、料金が発生することがある。
- Gemini APIキーは端末の現在のアプリ実行中のみ保持。写真データは指定された場合のみ縮小して送信。
- CI単体テスト・Androidビルドは検証可能だが、実機でのAI通信・完成画像の品質は未検証。

## 全体点検に伴う追補
- 通常の階層探索とメインの一本道探索の双方で、既知AI種族を通常エンカウント候補に含める。既存の図鑑追跡を優先。
- 一本道での既知AI種族出現時にも初回の画像所有IDを参照し、元の64×64素材に紐付ける。
- 探索で出現したモンスターは実際の階層または一本道の歩数、通常／希少／ボス、出現経路を誕生条件に記録。
- ただし既存の最初の図鑑記録は勝手に変更しない。旧データの空欄は引き続き未記録。


## 初回召喚の障害修正（2026-11-23）
- 新規または旧セーブで、捕獲モンスター0体・召喚結晶0個の場合、端末ごとに一度だけウェルカム結晶1個を付与。Prefsフラグで再付与しない。
- 召喚画面に操作不能の理由（結晶不足、満員、戦闘中、生成処理中、AI APIキー未入力）を表示する。
- AI文字召喚は指示文が空欄でも既存デフォルト指示で生成可能。APIキーは引き続き必要。
- オフライン／ドット絵工房は、ゲーム状態が更新されないとき成功と表示しない。
- AI実通信の成功は利用者固有APIキー・Google側契約によって異なり、実機未検証。
