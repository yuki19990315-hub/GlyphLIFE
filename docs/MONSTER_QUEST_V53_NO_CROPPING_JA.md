# Monster Quest v5.3 — モンスター全身表示の修正

## 原因と対応

- 収録された30体分の64×64素材は、透明ピクセルで囲まれており、アルファ領域が枠端には触れていない。したがって、少なくとも収録PNGのキャンバス端で切れている問題は検出されなかった。
- 探索画面では、描画サイズを固定したあとで `padding(bottom=...)` を適用していた。結果、画像を描く内側の矩形だけが縮み、足元や大きな角・翼が見づらい表示になり得た。画像そのものは縮めず、画面内で四角い描画領域ごと移動させる構成に変更した。
- 背景の地面の高さ（画面高さの79%）と、64×64画像の透明な上下余白（8px）を計算し、キャラ全身を保持したまま接地させる。
- ボス戦の移動・自動ジャンプでも画像の外枠が画面に残ることを、240〜480dp幅の境界テストと144〜214dp高さのテストで確認する。
- 旧探索・チャレンジ・ホームでも、描画矩形を縮めるための `padding` を全体位置調整の `offset` に変更した。
- モンスターデザイン工房の固定256dp画像、合成確認の160dp+120dp画像列を、画面幅に合わせたレスポンシブな表示へ変更した。

## 仕様を維持した点

- 64×64の元データ、最大16色（透過色を含む）、全身表示、最近接4倍表示。
- ユーザーが取り込んだ画像や装備素材を、画面表示のために上書き・削除しない。
- 前進・後退時の自動「ぴょんぴょん」移動。ジャンプボタンなし。

## 検証範囲

- JUnit境界テストとAndroid CIのビルド／ユニットテスト。
- 実機画面のスクリーンショットと、生成時点で既に身体の一部が欠けている画像については別途確認が必要。
