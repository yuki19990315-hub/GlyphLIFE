# Monster Quest v5.2 — 前進・後退でぴょんぴょん跳ねる動き

## v5.1からの訂正

「ジャンプして移動」とは**独立したジャンプ操作を求める意味ではない**。『ひまつぶクエスト』で見られるような、前進・後退にともなってキャラクターが軽快に弾む移動アニメーションを指す。誤解からv5.1で追加したジャンプ専用ボタンを削除した。

- ◀ **後退**：押し続けると後ろへ移動し、キャラクターが自動で小さくジャンプする。
- ▶ **前進**：押し続けると前へ移動し、キャラクターが自動で小さくジャンプする。ボスの射程内では通常攻撃に切り替わる。
- 通常探索中は移動時間に応じて約380ms周期の山型バウンスアニメーションを表示。入力が止まれば立ち姿勢に戻る。
- ボス戦では移動開始時に約360msの小さな跳躍を開始し、移動し続けると繰り返す。ジャンプ専用入力は一切ない。
- ボスの弾は以前の位置別ではなく連続座標へ飛んできて、着弾地点から移動して避けられる。移動中の自動跳躍が地上弾の回避につながるタイミングもある。
- 主人公を上下へ動かすのはスプライトの表示位置のみ。64×64の原画・アーマー・全身余白は変更しない。

## テスト

- 前進・後退のどちらでも同じ移動バウンスになること、停止時に跳ねないことをテスト。
- ボスの移動で跳躍が開始・再開し、停止中には収束することをテスト。
- 地上弾・空中弾の当たり判定、着弾地点からの回避、被弾の重複防止、死亡時の報酬保持をテスト。
- Nothing Phone (4a) Pro実機での動きの自然さ・見切れは未検証。
