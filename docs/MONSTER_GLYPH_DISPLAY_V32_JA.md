# Monster Quest v3.2 — 全身とGlyph表示の役割分離

## 相談と原因
共有されたv3.0のスクリーンショットに表示されているのは「相棒：ルナ」であり、旧版では共通の丸い胴体を持つ手続き画像だった。v3.1でライゼル系統の固有64×64絵へ変更したが、スマホ画面の小さな152dp表示とGlyphの物理137点マスクでは輪郭や細部が分かりづらい。なお、v3.1の比較用PNGは全身の64×64素材を表示しており、それ自体が丸いマスクで切り取られていたわけではない。

## v3.2の修正
- スマホ上の相棒の64×64全身画像を152dpから幅いっぱい・高さ280dpへ拡大し、画像の角丸切り抜きを解除。工房の比較サムネイルも角丸切り抜きを解除し、サイズを108dpに増やした。
- ゲーム内の原画は64×64、表示は整数倍（256px）で引き伸ばす従来仕様を維持。
- Glyphの13×13表示には、全身イラストを物理137LEDの枠で欠けさせるのではなく、ライゼルは角付きの顔、ルナは光輪の顔に特化した専用シンボルを導入。進化段階による冠の追加と、待機中の瞬き1コマを追加。13×13で四肢・装甲を再現できると誤認させない。
- **例外対象はライゼルと標準ルナのみ。** それ以外は引き続き高解像度の元絵から13×13へ通常投影。
- ライゼル／ルナでもユーザーがカスタムアーマーを装着した場合は、独自シンボルよりその姿の実画像投影を優先。ユーザーが個体にインポートした64×64画像があれば、専用シンボルは使わずその画像を投影。
- 工房プレビュー、召喚後、進化後、GlyphLIFE送信用の4コマで、選んだ専用シンボルを同じ処理から生成。ゲーム中の64×64画像自体には適用しない。
- 既存のセーブデータ、種族名、属性、レベルは変更しない。

## 確認
`MonsterQuest-PixelArt-Preview/11-full-body-and-glyph-icon.png` は、上段にライゼル、下段にルナ、左に本来の全身64×64画像、右に物理マスク内に配置した13×13アイコンを並べて表示。
`FeaturedGlyphIconTest` は、全進化・4コマで物理マスク外が点灯しないこと、工房と召喚後の一致、ユーザー装備の優先を検証。

注意: 13×13のLED配置は物理的に円に近いため、全身形状の忠実な再現は不可能。今回の方針は **本編では全身、Glyphでは識別しやすい顔シンボル** と明確に分離すること。スマホ実機と背面の視認性・美術品質は未検証。
