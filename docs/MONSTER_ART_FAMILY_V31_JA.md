# Monster Quest v3.1 — モンスターの外観統一（第1段階）

## 今回確認した問題
- スクリーンショットの画面上部の個体は「相棒：ルナ（精霊・光）」であり、雷獣「ライゼル」とは別の表示対象。
- ルナには以前、64×64の固有素材がなく、共通の手続き描画を使用していた。
- ライゼル以外のモンスターも原則として汎用64px手続き描画であり、AIが書く詳細設定と画素構造は同一ではない。
- AIで名前・属性・説明・骨格を生成する機能は、**AI画像を生成する機能とは別**。外見が自動で精密なデザインに変わるわけではない。

## 修正内容
- 固有モンスター素材の参照用 `WildMonster.artFamily` を追加。空文字は既存の生成ルートとし、古いデータの読み込みを維持。
- ライゼル（雷・四足獣）の工房プレビューは `raizel` アート系統として保存し、召喚・捕獲・進化後も同じ3段階素材を使用する。旧版の「名前=ライゼル」のデータも引き続き表示。
- 体験用の初期相棒ルナ（精霊・光）を、共通描画から **ライゼルの固有64pxシルエットを基にした月光色の固定素材**へ変更。名前・属性・レベル・保存IDは変更しない。
- GlyphLIFEから連携した個体には、ルナが同名でもこの見た目を強制しない。
- `MonsterArtworkStore.spriteFor` は保存済みの画像を優先し、固有素材と64px処理、13×13 Glyph投影は従来経路を使用。新しい有料AI呼び出しはしない。

## 重要な制約
- **ルナはライゼルの別色版（同じ輪郭）を用いた暫定アート**。完全に描き下ろした固有キャラではない。高い造形品質と統一感を優先した第1段階の対応である。
- 10体型すべてに固有の画像素材を作成したわけではない。その他のほとんどのモンスターは従来のプログラム描画。
- AIが作った文章から外見を正確に再現することは未実装。画像を保持したい場合は既存の「画像生成／画像取り込み」機能を使い、図鑑の実表示を確認する。
- 工房で進化2・3を選んで召喚しても、ゲームルール上は進化1からスタートする。進化1のプレビューは従来どおり表示される。
- GitHub Actionsの `MonsterQuest-PixelArt-Preview/10-raizel-luna-3-stages.png` で両系統の3段階素材を比較できる。**実機画質の検証は別途必要**。

## 続く改善案
各種族に固有の造形・配色を持つ64pxスプライトを個別に作り、3段階の進化を同一キャラクターの延長で描き、部位ごとのドット絵モーションを追加する。実機で個性や画面サイズを比較したうえで追加する。
