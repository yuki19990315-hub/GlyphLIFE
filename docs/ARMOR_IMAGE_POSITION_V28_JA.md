# Monster Quest v2.8 — AI画像パーツの配置調整

## 対応した範囲
- 64×64本編スプライトに、素体と独立した画像パーツを頭・胸・尾・肩・背中・翼の6部位から選んで装着。
- **装備中の画像パーツを2px単位で上下左右に移動**。各部位±12pxを上限とし、Android UI操作から変更。
- `customArmorOffsets`を個体のセーブJSONに保存。旧データは(0,0)扱いで互換。
- 進化後も画像IDと位置を保持。融合は頭・胸・肩を親Aから、尾・背・翼を親Bから継承。
- **合成プレビューで画像パーツの実際の重なりを表示**。前段階では使えない画像パーツは、適用確認時のみ解放後の段階で描画して確認。
- 更新した64×64スプライトから256×256表示・PNG出力・待機アニメ・13×13 Glyph派生を生成。
- 素体の原画PNGと装備画像の原本PNGは書き換えず、位置はメタデータで扱う。

## 検証
- パーツ移動で合成ピクセルが変わる一方、素材原本が変わらないこと。
- 16色以下/64×64制約、Glyphデータ169bit、±12px制限、合成時の親由来座標の一貫性をテスト。
- 生成画像の比較PNGをCI成果物`MonsterQuest-PixelArt-Preview`へ追加。
- GitHub Actionsでテスト・APKビルド・公式Nothing SDK用コードのコンパイルを確認してから本ブランチをmainへ反映。
