# Monster Quest v3.3 — ライゼル進化3段階の本体ドット絵を再デザイン

## 目的
「ポケモンやデジモンのように、キャラクターとして識別できる強いシルエットと進化」を目標に、ライゼルの**64×64本編スプライトそのもの**を更新する。既存作品のキャラクターや固有パーツは使用せず、オリジナルの雷獣で統一した。

## 確定したアートディレクション
| | 形態 | 固有の特徴 |
|---|---|---|
| 進化1 | 小型の雷獣 | 大きな顔、2本の小さな角、4本脚、黄色く発光する尾先 |
| 進化2 | 成長した四足雷獣 | 長くなった角、肩の装甲、背中の雷棘、長い尾 |
| 進化3 | 強靱な装甲雷獣 | 大きく反った角、牙、肩の重装甲、強い四肢、電撃を帯びた尾 |

**共通色**は深い紫・藍色、淡いクリーム色、雷の黄色、金属の灰色。全ステージで「同じ種族が育った」と認識できる輪郭を保つ。

## 実装
- チャットで制作した雷獣ライゼルの3段階コンセプト図を参照し、下段の全身ドット絵をそれぞれ透明背景へ抽出、64×64へ収めた。
- 透明背景＋不透明15色以下。4bitパレットにしてソースコード `FeaturedPixelArt.kt` に埋め込む。アプリ起動時にダウンロードは不要。
- 対象は固定ライゼル（雷属性、四足獣）。旧セーブで `artFamily` のない「ライゼル」も新素材に移行する。
- `FeaturedCompanionArt` のデフォルトルナはライゼルの固有形状を月光色へ変換するため、新しい輪郭へ同時に更新される。
- それ以外のモンスターは従来の手続き生成・ユーザーインポート画像を継続。**インポート済みの個体画像は上書きしない。**
- 図鑑・バトル・工房は64px正本を使用し、256pxの見た目はニアレスト拡大。
- 13×13 Glyph用の顔シンボルはv3.2どおり別素材（全身絵を表示するわけではない）。
- 進化条件・ゲーム性能・セーブIDは変更しない。

## テストと表示確認
- `FeaturedPixelArtTest`: 3形態が独立したシルエットを持つ、64×64、背景透過、15色以下、画像枠からはみ出さない、旧データと明示指定の同一性を検証。
- 既存 `MonsterPixelPreviewTest` は `MonsterQuest-PixelArt-Preview/08-featured-raizel-3-stages.png` を実コードから出力。
- 単体テストやCIだけでは画質を保証できないため、実機表示の最終評価は別途必要。

## 未実装・注意
- 今回は**ライゼル1系統**のアート品質改善。10体型すべてが固有のモンスターになったわけではない。
- 画像生成コンセプト図を64pxへ変換しているため、形状の一部は64pxで単純化されている。完全な手描きピクセルアートと主張しない。
- 4コマ待機・3コマ攻撃は引き続き機械的な移動・瞬きベース。部位別の自然なアニメーションは今後の課題。
- Geminiが考える名前・設定文とゲームの自動描画を完全一致させる機能も未実装。

## 次のデザイン作業
ライゼルの表情と進化3の視認性を64px実機サイズで監査し、その基準を獣以外の龍・機甲・精霊などにも拡張する。
