# Glyph Snake — GlyphLIFE v0.13

## ミニゲーム
- 13×13論理ドットとPhone (4a) Proの実LED137点の円形マスク内だけを移動するヘビゲーム。
- 上下左右ボタンで方向転換。反対向きへの即時反転は不可。
- エサを食べるごとに1点獲得し、体が1マス伸びる。LED範囲外や自分の体に衝突すると終了。
- ゲーム状態は端末内のみ。最高スコアは端末に保存される。
- 速度は180～650ms/コマ。停止・再開と新しいゲームを提供。
- 標準APKではスマホ画面上のみで遊べる。SDK付きAPKでは前景中、任意で背面Glyphへフレーム送信する。
- **直近64コマのリプレイ**をCreatorに読み込む、または名前付き作品としてギャラリー保存できる。
- Creatorへの読み込みは編集データ上書きの確認を要求する。
- 「遊び」タブにFluidとSnakeの切り替えを配置し、メインナビの項目数は5個のまま。
- ネット通信、広告、アカウント、AI APIキーは不要。

## テストと制限
- 単体テストでエサの配置、移動、反転禁止、食事、衝突、最後尾への移動を検証。
- 背面Glyphの描画と更新間隔は実機未検証。
- UIのタッチ操作、画面回転、保存リプレイの見え方は実機確認が必要。
- ゲームの途中状態は保存しない（最高スコアのみ保存）。アプリから離れると新しいゲームになる。
