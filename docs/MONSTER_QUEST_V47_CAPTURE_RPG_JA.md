# Monster Quest v4.7 — 捕獲・育成RPGへの整理

## 方針
- メトロイドヴァニア用の6エリア、横スクロール移動、ジャンプ、二段ジャンプ、ダッシュ、物理演算、隠し通路、封印扉を今回の現行版から削除。
- **探索タブを従来のタップ進行型ダンジョン探索に戻す**。歩く→ランダム遭遇→戦闘か捕獲→分岐→5階おきのボス戦。挑戦タブの試練の塔・アリーナは継続。
- v4.6の横スクロール専用セーブフィールドは読み込まず、今後も保存しません。**共通だった個体、レベル、経験値、編成、BOSS装備、アイテム、旧タップ探索進行、塔、アリーナのデータは引き続き保持**します。
- モンスター画像表示の見切れ対策（アニメーションとBOSS装備を含む全身64×64スプライトの安全余白）を残します。元画像自体の欠損修復とは異なります。

## 新機能：図鑑から捕獲対象を追跡
- ホーム → **図鑑** → 対象モンスターの **追跡する** を押す。
- 発見済みの通常種族のみ指定できます。以後、通常ランダム遭遇の **45%** でその種族が選択されます（**確定ではありません**）。残りは従来の通常抽選。5階おきのBOSS出現と報酬は従来通りです。
- 追跡を解除すると従来の完全ランダム遭遇に戻ります。
- AIで生成・登録した種族も、図鑑に登録されていれば追跡可能。個別の元画像を持つ種族はその参照を維持します。
- 同種族を繰り返し捕獲しても、遭遇時のUUIDは毎回別。捕獲個体の **追加スキル**、レベル5／15／30で解放される **3つの潜在能力** が個体別に決まり、同じ種類の能力が3つ重複する可能性も残します。
- 従来のセーブに追跡項目がない場合は未指定として読み込みます。捕獲対象の指定はアプリ内で変更可能。

## 変更せず維持するシステム
- 3匹までのパーティ編成と戦闘援護
- 個体別のレベル、経験値、勝利数、3段階の進化
- 固有スキル＋ランダム追加スキル、独立した再使用カウント
- ボス装備6種類と見た目の変化
- 毎レベルごとの能力アップ＋Lv5／15／30の個別ランダムステータス
- 合成と装備工房、64×64ドット絵の表示・素材・Glyph変換
- ショップ、回復薬、捕獲玉、召喚結晶、探索報酬、塔とアリーナ

## 今回は追加しないもの
Monster Sanctuary風の「モンスターごとの探索能力で通れる場所が増える」案は将来候補です。現行版には未実装とし、今回の探索システムには組み込みません。

## 検証範囲
JUnitテストで追跡対象選択／拒否、遭遇抽選の確率的分布、種族の複数個体捕獲、ボスの独立性、AI種族の画像参照、レガシー図鑑でボス名が誤って追跡されないことを確認します。Androidビルドの成功は実機の操作感と全てのセーブデータの互換を保証するものではありません。
