# Monster Quest v2.8.2 — 画像パーツの非破壊サイズ調整

## 追加した機能
- 既存のAI生成／取り込みPNG装備を維持したまま、**サイズを50〜150%** の範囲で10%単位に変更。
- スロット別の位置設定 `ArmorOffset` に `scalePercent` を追加。以前の X/Y ±12px調整はそのまま利用。
- 元の64×64透過PNGは改変せず、描画時だけサイズ変更。背景透過／素体の16色以下パレットを維持。
- `customArmorOffsets` のJSONに `scale` を保存。旧セーブでは `scale` が無い場合は100%として読み込み。
- 進化では装備データを保持し、融合では親A（頭・胸・肩）・親B（尾・背中・翼）に対応する位置とサイズを継承。
- 戦闘・図鑑・待機アニメ・64/256px PNG・13×13 Glyphが同じ合成スプライトを使用。
- カスタム画像装着中の仲間を「研究所」で選択すると、小さく／大きくボタンを使用可能。
- 5種類のサイズ比較PNGをGitHub Actionsで生成し、色数・画像変化・変形値の上限をテストする。

## 未検証
- AI生成サービスの実通信、課金の有無、生成画像品質、Nothing Phone (4a) Pro実機操作。
- 実機上の小画面での視認性。元画像が不透明背景のときの背景透過は既存の制約がある。
