# Monster Quest v4.9 — 片手探索と奥義・精霊の祠

## 既存の探索から引き継ぐもの

- 右側長押しで前進と自動攻撃、左側で後退／退却。手動連打も有効。
- 3階ごとの分岐、5階ごとのボス、希少モンスターと捕獲、装備とチーム育成。
- 主人公と敵の64×64原画を流用し、既存の進化・Glyph変換・画像装備を維持。
- セーブデータは旧 `monsterquest_v1` キーのまま。新項目のない記録には安全な初期値を使用。

## 今回追加する遊び

### 奥義（小さなリスクと気持ちよい決着）

- 通常攻撃が当たると奥義ゲージ+15、ボスの予告を読んでジャスト回避すると+30。
- 最大100、戦闘をまたいで持ち越す。満タンなら「✦ 奥義」で全敵種に大ダメージ。
- 強さは相棒レベル、連勝、相手の最大HPで変わる。ボスを一撃で飛ばす前提ではない。
- 1回の奥義でゲージを0に戻す。敗北時も0にする。
- 奥義の撃破には通常の勝利・経験値・戦利品・ボス固有装備ルールをそのまま使用。

### 精霊の祠（探索中の選択）

- 2F、6F、10F…（4で割って2余る階）の3歩目以降、次に進もうとすると祠を発見。
- **癒し**：HPを50+現在階層回復（上限あり）。
- **物資**：捕獲玉を2個獲得（上限99）。
- **契約**：最大HPの約25%を代償として召喚結晶2個を獲得。HPは1未満にならない。
- その階の祠は1回だけ。選択まで移動と自動進行を停止し、長押しでは選択されない。
- 訪問数、直近の祠の階、選択待機中の状態を保存する。

### UIと実用性

- 探索フィールドとHP/EXPゲージは上部に固定。
- 下部には前進・後退、捕獲、回復、奥義、スキルボタンを常時表示。
- 資源、商人、捕獲設定、スキル一覧などは中央のスクロール領域にまとめる。
- ボス戦は攻撃予告の左右方向を明示。入力側と残り時間を読み取れる。
- 分岐・祠の決定肢は下側の操作領域に表示し、誤った長押し選択を防ぐ。
- 狭い画面は画面中央の情報をスクロールできるが、攻撃操作ボタンは外へ逃げない。
