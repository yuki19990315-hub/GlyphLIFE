# Monster Quest ボス戦・戦闘拡張 v0.3

- 5部屋の最終部屋に**ボス（3種のうち1種）**が出現。
- ボスは通常の敵と異なるHP/攻撃力を持ち、HPが半分以下になると攻撃力が上昇する。
- ボスは捕獲不可。倒すと最後の部屋がクリアとなり報酬が追加される。
- **防御**：敵の攻撃を軽減する代わりに攻撃できない。
- **回復薬**：冒険開始時に2個所持。HPを回復し、そのターンに敵の反撃も受ける。
- 回復薬、ボス情報などの状態は端末に保存され、Androidアプリ再起動時に再開可能。
- ボスの見た目は画面上のテキスト表示が中心。後続版でモンスターごとの戦闘グラフィックを強化する。
- 本バージョンも端末実機プレイテストは未実施。GitHub ActionsのKotlin単体テストとAPKビルドで検証。
