# GlyphLIFE / Monster Quest 現行仕様書 v0.10

更新日: 2026-11-11。実装状況の詳細は`RELEASE_STATUS_JA.md`参照。

## 1. 構成と対象
- **GlyphLIFE**：Nothing Phone (4a) Pro向けのAIペット＋ドット絵/アニメ制作＋Fluid Lab＋NFCリング対応アプリ。
- **Monster Quest**：同一リポジトリ内の別のAndroid APK。ゲームは単独で動作し、GlyphLIFEからペットを受け取れる。
- GlyphLIFEの論理画素は13×13（169マス）、実LEDは円形の137マス。非LED部分を編集対象から外す。
- Kotlin / Jetpack Composeを採用。Monster Questも現行MVPはCompose製であり、Godotへは未移植。

## 2. GlyphLIFE — ペット
- 最大20匹を保存し、個体ID・名前・種族・属性・性格・経験値・幸福度・元気を保持。
- 卵をかえし、ペットごとのアニメーションと会話履歴を端末内保存。旧単体ペットデータの移行処理あり。
- 遊ぶ、ごはん、休むで経験値・元気・幸福度が変化。放置で消滅させない方針。
- Lv5とLv12の成長段階があり、種族別の3コマアニメを生成する（既存の手描き画像は明示確認後に上書き）。
- キーなしではオフライン定型会話。任意入力のGemini APIキーで生成AI会話ができる設計。ただし実通信未検証。
- 性格変化、睡眠/食習慣、歩数連動、ペット図鑑、長期記憶の高度化は未実装。

## 3. GlyphLIFE — Creator
- 13×13ドット絵描画、指でなぞる描画、消しゴム、塗りつぶし、Undo/Redo、左右上下反転、回転、色反転。
- 最大64フレーム、各100～2000ms、フレーム追加・複製・削除・再生。
- 画像から13×13への変換、PNG、PNGスプライトシート、アニメJSONの読み込み/共有、名前付き作品を最大30件保存。
- Gemini経由の文章からアニメ生成は任意のAPIキーで使用する実装。13×13の169桁を検証し不正回答を拒否。実通信は未検証。
- 前景Glyph Matrixは`setAppMatrixFrame`、AOD Toyは`setMatrixFrame`。SDK 2.0でコンパイル検証成功、実機点灯は未検証。
- AOD ToyはPhone (4a) Proの約1分ごとのイベントに合わせる。前景の高FPSアニメとは異なる。
- GIF/APNG出力、複数作品の一括バックアップは未実装。

## 4. GlyphLIFE — Fluid Lab / NFCリング
- 137LEDマスク内で粒子を重力方向へ移動する水のようなセルオートマトン。厳密な流体力学ソルバーではない。
- 再生/一時停止、重力4方向、速度調整、加速度センサーによる傾斜、粒子追加、Creatorへのコピー。
- NFCリングを明示的に登録し、読み取るたびPet/Creator/Fluidを切り替える。読取りはアプリ前景のみ。
- NFCの生UIDは外部送信せずSHA-256の照合値を端末に保存。UIDは認証に使えない、ランダム化されるリングもある。
- NFCと加速度センサーの実機動作は未検証。

## 5. Monster Quest
- 別APKで起動できる4×4の5部屋探索ゲーム。必ず最終敵へ行ける経路がある。
- 属性攻撃、通常攻撃、防御、回復薬（初期2個）、捕獲、ローカル保存。
- 5部屋目はボス戦。ボスは捕獲不可で、半分以下のHPで攻撃が強化される。
- オフラインの独自ドット絵と、任意のGemini生成モンスターの名前・属性・説明・13×13アートを表示。
- AIにHP・攻撃力・経験値の決定権は与えず、ゲームルールで計算する。
- GlyphLIFEとのペット交換はAndroidのJSON v1送受信。結果イベントID・対象ペットID・報酬の上限を検証、二重反映を防ぐ。
- 高解像度ゲームアート、アクション戦闘、複数属性装備、より大きいマップ、オンラインランキングは後続フェーズ。
- 現在の連携JSONに改ざん防止署名はなく、競争用の信頼済み報酬として扱わない。

## 6. AIとプライバシー
- Gemini APIキーはアプリの実行中メモリにのみ保持し、APKに同梱しない。
- API呼び出しは利用者のボタン操作時のみ。会話内容や写真はGoogleへ送信され得ることをUIに明記。
- キーなしでも基本のペット・編集・探索・戦闘・流体シミュレーションはオフライン動作。
- Gemini APIの料金・利用枠・プライバシーはGoogle提供条件に従う。ネットワーク動作は未検証。

## 7. 検証とリリース境界
- GitHub Actions: SDKなしの2APKビルド＋単体テスト成功。
