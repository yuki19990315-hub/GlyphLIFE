# Monster Quest v2.7 — AI画像をパーツとして装着する機能

## 結論
既存の64×64ドット絵モンスターに、画像生成AIまたはユーザーが用意した透過画像の**単体パーツ**を装着できるコードを追加。

## 操作
1. 捕獲図鑑・合成を開き、対象モンスターを素材Aとして選択。
2. 「選んだ仲間の装備を編集」で頭・胸・尾・肩・背中・翼のいずれかを選択。
3. 「画像パーツを選ぶ」でローカル画像を読み込むか、APIキー入力後に「AIでパーツ画像生成」で有料の外部画像生成を起動。
4. 透過背景または四隅がマゼンタの画像のみ受理。64×64の素体と重ねた結果をプレビューして「この画像を装着」で確定。キャンセルで破棄。
5. 進化前の部位は解放段階で自動表示。融合時には対象部位に従って親のPNG参照を継承する。

## 仕組み
- 個別パーツ画像：アプリ内部の`monster_armor_layers_v1/<UUID>.png`へ64×64として保存。
- JSON保存：`WildMonster.customArmorParts`にスロット名と画像UUIDの対応だけ保存。パスやネットワークURLを受け取らない。
- 画像はクロマキー透過して中心化し、装着時は既存の10体型に応じた固定マウント位置へ配置。写真の背景、全身画像は誤装着を防ぐため拒否する。
- 外部パーツの色は元のスプライトのパレットへ制限し、最大16色を維持。
- 背中・翼は素体の背後、その他は前面へ合成。未解放段階は非表示。
- 進化でも同じUUIDを保持。融合では親AのHEAD/CORE/SHOULDER、親BのTAIL/BACK/WINGを引き継ぐ。
- モンスターの描画、PNG出力、Glyph13×13表示、GlyphLIFE連携の前に共通の`spriteFor()`を利用する。

## 制限
- AI生成画像がパーツとして正しく抜けるか、格好良いデザインになるかはAPI実通信・実機で未確認。
- 完全な手描きの部位別モーションや、骨格に応じた自由変形は未実装。
- 既存の保存画像は消さず、解除した共有画像を自動削除しない。セーブ・融合先で同じパーツを参照し得る。
- Google画像生成APIは利用料金が発生し得る。APIキーは設定として保存しない。
- Nothing実機の背面LEDの見え方は別途検証が必要。
