# Glyph Creator作品ギャラリー

## 実装
- 手動保存で名前を付けたアニメーションを最大30件保管する。
- 画面上のドット絵とフレーム長を保管し、作品を開くと現在の編集データに読み込む。
- 既存のペットごとの自動保存データとは別領域。別ペットへ切り替えても作品は残る。
- 保存済み作品の削除は確認ダイアログから行う。
- 入力名は1～40文字。作品は端末内SharedPreferences（`glyph_gallery_v1`）に保存される。
- JSONアニメーション出力、PNGフレーム出力、PNGスプライトシート出力も利用可能。
- このギャラリーはMVP用の小規模保存方式であり、作品数・フレーム数が増えたらRoom/ファイルに移行する。
