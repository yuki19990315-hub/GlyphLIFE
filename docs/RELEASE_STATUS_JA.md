## SDK検証により判明した事実

1. Nothing公式`glyph-matrix-sdk-2.0.aar`は最低Android API33を要求。SDKなしGlyphLIFEはAPI29以上を維持。
2. 使用したSDKでは`GlyphMatrixFrame.Builder.build(Context)`の呼び出しが必要。公式READMEの一部サンプル表記とは差異があったが、**実際のAARに対するコンパイラの結果を優先**した。
3. GitHub Actionsの`glyph-sdk-compile`ではSDKを公式URLから一時取得し、SDKを含むAPKをアップロードしない。
4. 通常の`build`ジョブはSDKなしのGlyphLIFEとMonster Questの2つのデバッグAPKをアーティファクトとして公開する。

## Monster Quest v3.0 — 非破壊アーマー配置エディター（2026-11-12）

- 既存の装備パーツの位置と倍率を調整中は保存しない。64×64の姿を見て「この配置を保存」で反映、キャンセルなら変更なし。
- 位置は1px刻み（縦横±12px）、倍率は5%刻み（50〜150%）。すべて制限内へ補正。
- AI生成直後・画像取込直後・保存済みパーツ再利用時にも、初回の装着前に同じ位置と大きさの調整UIを表示。
- 進化未解放パーツは対象進化後の完成予想を表示するだけで、実際の進化段階は変更しない。
- 配置プレビューと確定時は同じ純粋なArmorPlacementDraft関数を使い、装着位置・画像IDの整合性を保つ。
- 新規生成・取込画像をキャンセルした場合の一時ファイル破棄と、共有ライブラリパーツの保護は従来通り。
- Gemini API実通信、画質・位置合わせの実機評価は未検証。最新ビルド・テストはGitHub Actions参照。
