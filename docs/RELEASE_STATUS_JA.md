# GlyphLIFE v0.3 実装・検証ステータス

## 追加した機能（ソース上）
1. Phone (4a) Proの実際の137LEDを反映した円形マスク（13×13論理グリッド中の四隅32マス無効）。
2. 13×13 × 1～64枚のアニメーション編集、長さ指定、再生、複製、削除。
2. ペン、消しゴム、塗りつぶし、左右反転、上下反転、90度回転、色反転、Undo/Redo。
3. 画像の13×13化（Floyd–Steinberg処理）、PNG保存、アニメーションJSONの入出力。
4. ペットの卵生成、育成ステータス、ローカル会話履歴。
5. Gemini APIキーを利用者がセッション中に入力すれば、生成AI会話/ドット絵の文章生成。
6. Monster Quest用ペット書き出しと結果取り込み（個体・UUID・報酬上限・重複の基本検証）。
7. Nothing公式AARを手動導入した場合に限る、背面Glyphへの前景アニメーションライブ送信アダプタ。

## 注意
- GitHub ActionsはAARなしのstubで自動ビルドする。実機の背面点灯確認とは別。
- Gemini実API呼び出しはキー未提供のため未検証。Googleの無料枠・課金条件は変化する。
- Pixelデータは169桁の二値データ。Gemini応答はサイズ、桁数、フレーム数、長さを厳密検査する。
- 公式SDK・AOD Toyはライフサイクルが別。AOD常駐・滑らかなアニメーションは未保証。
- このビルドはMonster Quest本体ではなく、データ連携に向けた受け皿。
- リポジトリ公開のためAI秘密鍵・認証鍵・署名ファイルをコミットしない。
