# Monster Quest v4.5 — ボス装備の外見反映・ランダム追加スキル・個体別能力スロット

## ボス装備の見た目
ホーム・探検・試練の塔・アリーナのメインモンスター、ホームの仲間一覧に、装着したボス装備を**小さなドット絵の紋章**として重ねます。
- 6装備に対応した別々の紋章（牙、歯車、星、核、珠、時計）。
- 64×64の実ドット格子と、元の色パレット（最大16色）を維持。全身の顔や元デザインを置き換えない。
- 元のキャラ画像・保存したオリジナル素材を変更せず、描画時にだけ重ねる。装備解除時は元に戻る。
- この版の装備表示は**ゲーム画面のアニメーション画像**に対するもの。Glyph実機・PNG書き出しへ同じ紋章を常時反映する変更は含まない。

## 追加のランダムスキル
各個体には既存の種族固有スキル1個に加えて、**13系統の中から別のランダム追加スキル1個**が割り振られます。
- 追加スキルは元の固有スキルと同じものにならない。
- 個体IDによる固定抽選なので、再起動・進化後も変わらない。同種の別個体は結果が違う場合がある。
- ホーム → パーティ詳細で追加スキルを確認。
- 探検・塔・アリーナで、各モンスターの「✦元の固有スキル」「◆追加スキル」をそれぞれ発動。クールダウンは独立しており、通常攻撃の回数で減る。
- 新規捕獲、召喚、融合後の新個体に付与。v4.4以前の既存個体もデータ初期化なしで個体IDから一度だけ能力が確定。

## 個体別のランダム能力スロット
同種でも育成結果を変える3つの恒久スロットです。

| スロット | 解放条件 | 抽選内容 |
|---|---|---|
| 1 | Lv5 | 攻撃／防御／最大HP／会心率からランダム |
| 2 | Lv15 | 同上。前の抽選結果は変わらない |
| 3 | Lv30 | 同上。これまでの2スロットを保持 |

- それぞれ★1・★2・★3のランダムな強さ。★3は10%、★2は27%、★1は63%。
- スロットの種類・値・レア度は個体IDから固定され、再起動しても変化しません。
- 同じステータスが複数スロットに出る場合は加算（過度な値は上限で制限）。
- **出撃中の最大3匹と相棒**の能力が戦闘で合算。攻撃・防御・会心率・最大HPに実際に反映。HPはチーム能力値によって100から最大200まで増加。
- ホーム → パーティに全3スロットを表示。未開放は「Lv5で解放」のように示します。
- 元の進化段階・スキル・個体ID・装備・育成は保持。

## セーブ仕様
- v4.4のセーブキーは維持。Companion / WildMonsterに追加スキルのIDとStatSlot配列を追加。
- 旧セーブではレベルに応じた解放済みスロットを個体IDから決定。既存の仲間、ボス装備、塔・アリーナ記録は削除しない。
- 新たに捕獲・召喚する仲間には新しい個体IDが発行され、同種でも違う抽選結果が生成され得る。
- 画像リソースは変更しないため、取り込み済みのモンスター画像やドット絵の設計は維持。
- レア値やドロップ率は初期バランス。実機での描画・タップ操作は別途確認が必要。
