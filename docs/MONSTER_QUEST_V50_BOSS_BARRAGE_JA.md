# Monster Quest v5.0 — 前後移動で避けるボス弾幕

## 体験設計

「ひまつぶクエスト」の片手で進められる気軽さはそのままに、5階ごとに現れるボスには独自の**前後回避型弾幕**を追加する。敵画像・弾・背景は自作のドット絵描画を利用し、他作品のデータは使用しない。

- ボス戦の足場は横一列の**5地点**（左が後方、右が前方）。左右ボタンを単押し・長押しして一つずつ移動する。
- **最前列に到達すると**右ボタンが攻撃になる。後退している間は通常攻撃が届かないため、位置取りが攻撃と防御の駆け引きになる。
- ボスは複数の**弾**を射出する。発射直後から足場に赤い**着弾予告**が表示され、弾がそこへ落下してくる。
- 着弾地点にプレイヤーがいるとダメージ。着弾時までに前後へ移動すれば回避できる。連続弾の一群につき被弾は最大1回。
- 全弾を避けると**弱点露出（次の3回の通常攻撃が3倍）**＋**奥義ゲージ30%**。攻撃と回避を交互に繰り返す。
- ボスHPが半分以下になると**怒りの弾幕**。5地点中4地点を狙うが、必ず最低1地点の安全地帯を残す。視認可能な予告があり、予測不能な全域同時被弾はない。
- ボス戦中の弾幕はゲーム画面のタイマーだけで進行し、探索タブを離れた間は停止する。

## 見切れ・画面構成の対策

1. ボス戦のプレイヤーと敵を**画面幅に比例した別々の領域**に縮小して収め、全身を表示する。64×64・最大16色の原画は従来の表示時の余白補正を維持。
2. 小さな端末では探索ステージを214dpから177dp / 144dpに縮小し、操作ボタンを85dpから72dp / 62dpに変更。HP・EXPは固定、その他の情報はスクロール可能。
3. ボス戦の別置き「左右回避」ボタンを削除。**下部の2つの主ボタンだけ**で移動・通常攻撃ができるようにした。
4. 旧タップモードと挑戦モードの戦闘スプライトも画面幅に応じて縮小し、細身画面で重ならないように調整。
5. 弾はドットグリッドに沿う四角形の重ね描画で、発射位置・飛翔中の位置・地面の着弾予告を同時に表示する。

## 互換性とテスト

- `TapRun`の新項目（プレイヤー位置、弾配列、次の発射までの時間、弾幕回数、回避成功回数）は**任意のJSONキー**。v4.9以前のデータには初期値を補って読み込む。
- 旧タップ操作のボス処理はそのまま残す。
- モデルのテストは、安全地帯の存在、最前列だけ攻撃可能、被弾1回まで、弾幕の報酬、怒り状態、敗北時の引き継ぎ、長押し移動を検証する。
- **未検証**：Nothing Phone (4a) Pro実機でのタッチ・画面表示、光・速度・弾幕密度のプレイフィール。ビルド成功は端末での遊びやすさを保証しない。
