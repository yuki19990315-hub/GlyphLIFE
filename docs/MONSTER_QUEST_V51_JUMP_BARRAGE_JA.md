# Monster Quest v5.1 — 走る・ジャンプするボス戦

## v5.0からの変更

前のバージョンにあった**5地点移動**を撤廃。プレイヤーの水平位置は連続的な数値で保持し、長押しで滑らかに前後移動する。地面は単一の横方向ステージで、前進・後退・ジャンプの3操作で弾幕を避けられる。

1. **◀ 後退**：押している間、敵から離れる。ボス戦から逃走はしない。
2. **▶ 前進／攻撃**：押している間、ボスに近づく。攻撃射程に入ると連打・長押しで通常攻撃。射程外からは攻撃できない。
3. **▲ ジャンプ**：900msの弧を描いて跳ぶ。空中での横移動も可能。着地後250msの短いクールダウン。

## 回避ルール

- **赤い地上弾**は着弾地点と着弾時刻を見て前後に避けるか、タイミングよくジャンプして飛び越える。
- **青い空中弾**は跳ぶと危険。地上でやり過ごすか、位置をずらして避ける。
- 弾の飛翔位置と着弾予告は同じスクリーン座標系に表示する。プレイヤーのジャンプも実際の絵の上下移動に反映。
- ボスの弾幕は単発の狙い撃ち、空中弾との混合、時間差の地上弾。HPが半分以下になると弾数が増える。
- 同じ一群で被弾するのは最大1回。全て避けると弱点露出（次の攻撃3回が3倍）と奥義ゲージ+30%。
- ジャンプ時間・位置・飛翔中の弾・次の弾幕をセーブする。旧v5.0の5地点セーブは新しい位置で初期化し、古い弾は破棄して進められるようにする。

## 見切れ・操作UI

- 主人公とボスは画面幅でサイズ上限を決定し、全身の透明余白を維持する。
- ボス戦中は下部の操作列を「◀ 後退」「▲ ジャンプ」「▶ 前進/攻撃」にする。各ボタンは縦積みの短いラベルなので狭い画面でも文字が隠れにくい。
- 体力・経験値と弾幕画面は固定表示、細かなゲーム情報は中央のスクロール領域へ移動。

## 検証と制限

- ジャンプ中の横移動、地上弾のジャンプ回避、空中弾でのジャンプ被弾、位置移動回避、同一弾幕からの多重ダメージ防止、弾幕パターン、死亡時の成長維持を自動テストする。
- 実機のフレームレート・タッチ操作・画面サイズは実機検証が必要。Androidビルドとモデルテストの成功だけでは触り心地を保証しない。
