# NFCリング切り替え（実装 v1）

## 仕組み
1. GlyphLIFEの「連携」画面からNFCリングを登録する。
2. AndroidのNFCリーダーモードで、次に読み取ったNFCタグのUIDをSHA-256ハッシュに変換して保存。
3. 使用を明示的にONにすると、GlyphLIFEが**前景にある間だけ**登録済みリングを監視。
4. 同じタグをかざすごとに「Pet → Creator → Fluid → Pet」の3つのモードを切り替える。
5. 公式Glyph SDKが使えるローカルビルドでは、対応する画面のドット絵を背面Glyphへ送信を試みる。SDKなしビルドでは画面切り替えのみ。

## セキュリティ/互換性
- 端末内のプライベートSharedPreferencesにSHA-256化したUIDを保存。生UIDやタグ内容を外部へ送信しない。
- UIDは認証鍵ではない。偽造可能なものや毎回変わるランダムUIDのNFCリングでは機能しない。
- 対応NFCタグはNFC-A/B/F/Vリーダーモードで検出されるもの。すべてのNFCリングを保証しない。
- NFCのない端末では機能を無効化。
- 1回のタップで複数回切り替わらないよう、同じタグの読み取りを約1.5秒抑制。
- バックグラウンド常時NFC監視はしない。OSの仕様に従って画面が離れるとリーダーモード停止。
- 実機でのNFC認識・Glyph制御は未検証。リングを登録して動作確認する工程が残る。
