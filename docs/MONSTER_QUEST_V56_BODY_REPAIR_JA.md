# Monster Quest v5.6 — 64×64モンスター全身描画の元画像修復

## 修復対象

v4.1で承認されたモンスター画像の一部は、`64×64` の枠に余白があっても、
**素材化前に鼻先、手、尾、体の右側などが切断された状態**だった。
`fitWithMargin()` は今ある画素を縮小するだけなので、欠損を復元できない。

10系統×3段階＝30枚を確認し、修復が必要と判断した27枚を、
欠けた部位まで含めた透明PNGに更新した。魔眼系の3枚は元絵を維持した。

全30枚の一覧：`docs/MONSTER_QUEST_V56_BODY_REPAIR_QA.png`

## 仕様・保存先

- 編集可能なPNG原本：`monsterquest/art_sources/repairs_v56/*.png`
- 各原本：64×64・透過色を含む最大16色・アルファ中間値なし
- 描画領域：四辺に**8ピクセル以上**の透明余白を確保
- ランタイム：`CuratedMonsterRepairs.kt` に可逆な4bit圧縮画素として埋め込み
- 呼び出し：既存の`CuratedMonsterArt`が修復された段階だけ優先して使用
- 従来のアニメーション、Glyph全身投影、所持データは変更しない

### PNG変更後の更新

```sh
python scripts/package_curated_repairs.py
```

生成前の元絵監査：`python scripts/audit_curated_sprites.py`

## チェック

- 画像一覧で、鼻先・羽先・手足・尻尾の形が終端まで描かれているか目視確認
- 修復された27枚が実際にゲーム側の素材選択で使用されているか確認
- `CuratedMonsterRepairsTest` で解像度、色数、透明度、透明マージンを検証
- 実機／エミュレータで全身、敵との距離、端末比率、アニメーションの見切れを確認

**注意：** 画像の端に余白があることと、キャラクターの造形が完成していることは別。
機械的なテストだけでは描き漏れを判断できないため、最終的なデザイン品質は
一覧画像と実ゲーム画面で判断する。実機の動作確認が完了するまでは完成とは扱わない。
